Android-App bauen und in Google Play hochladen

Viva-Deluxe App (de.vivadeluxe.app) · eine App für Mitarbeitende und Büro · Stand 14.10.2026

Schon erledigt: Das Android-Projekt liegt fertig im Repository (Ordner mobile-app/android) – mit App-Name „Viva-Deluxe“, Paketname de.vivadeluxe.app, Bordeaux-Icon, Startbild, Kamera-Berechtigung für den QR-Scanner. Die App lädt die Seiten vom Server (app.viva-deluxe-reinigung.de/app): neue Funktionen sind sofort in der App, ohne neues Store-Update.

Schritt 1 – Einmalig: Node.js installieren

  1. nodejs.org → Version LTS herunterladen und installieren (alles mit „Weiter“).

Schritt 2 – Projekt herunterladen

  1. github.com → Repository viva4975-art/owner → oben links Branch claude/new-session-t3lg2s wählen.
  2. Grüner Knopf Code → Download ZIP, ZIP entpacken (z. B. nach C:\viva).
  3. Im entpackten Ordner den Unterordner mobile-app öffnen, oben in die Adresszeile cmd tippen, Enter – es öffnet sich ein schwarzes Fenster in diesem Ordner. Dort eingeben:
npm install
npx cap sync android

Dauert 1–2 Minuten. Am Ende steht „Sync finished“.

Schritt 3 – In Android Studio öffnen und auf dem Handy testen

  1. Android Studio → Open → Ordner mobile-app\android wählen (nicht mobile-app).
  2. Java 21 einstellen (sonst Meldung „Gradle … incompatible with the Gradle JVM version 25“): File → Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK = jbr-21 (fehlt sie: „Download JDK…“ → Version 21) → OK → File → Sync Project with Gradle Files.
  3. Warten, bis unten „Gradle sync finished“ steht (beim ersten Mal einige Minuten, lädt Werkzeuge nach). Fragt Android Studio nach einem Update von Gradle/AGP: nicht aktualisieren.
  4. Ohne Android-Handy: rechts Device Manager → + → Create Virtual Device → Pixel 8 → System-Image API 35 herunterladen → Finish. (Mit Handy: Einstellungen → Über das Telefon → 7× auf Build-Nummer → Entwickleroptionen → USB-Debugging an, per USB anschließen.)
  5. Oben das Gerät auswählen und auf ▶ Run klicken. Die App startet mit der Anmeldung. Der Test ist freiwillig – man kann auch direkt Schritt 4 machen und über den internen Test in Google Play prüfen.

Schritt 4 – Datei für Google Play erzeugen (.aab)

  1. Menü Build → Generate Signed App Bundle or APK → Android App Bundle → Next.
  2. Bei „Key store path“ Create new…: Speicherort z. B. C:\viva-schluessel\upload.jks, Passwort vergeben, Alias upload, Name „Ahmed Chomontek“, Organisation „Viva-Deluxe Gebäudereinigung GmbH“, Land DE.
  3. Next → release → Create. Die Datei liegt danach unter mobile-app\android\app\release\app-release.aab.
Wichtig: Die Schlüsseldatei upload.jks und ihr Passwort sicher aufbewahren (Passwort-Manager + Sicherungskopie, nicht in den Chat, nicht ins Repository). Ohne sie lassen sich keine Updates hochladen. Bei Verlust kann Google den Upload-Schlüssel zurücksetzen (Play App Signing) – das dauert aber Tage.

Schritt 5 – In der Play Console hochladen

  1. play.google.com/console → App erstellen: Name „Viva-Deluxe“, Sprache Deutsch, App, kostenlos, Erklärungen bestätigen.
  2. Links Testen → Interner Test → Tester: E-Mail-Liste anlegen (Gmail-Adressen der Testpersonen) → Neuen Release erstellen → app-release.aab hochladen → Versionshinweis „Erste Version“ → speichern → Release prüfen → Einführen.
  3. Unter „Tester“ den Link zur Teilnahme kopieren und an die Tester schicken. Interne Tests sind meist nach wenigen Minuten verfügbar (ohne Prüfung durch Google).

Schritt 6 – Für alle Mitarbeitenden freigeben

Vor der Freigabe will Google unter App-Inhalte einige Angaben:

AngabeWas eintragen
Datenschutzerklärung (URL)Pflicht. Seite mit den Datenschutzhinweisen zur App (Art. 13 DSGVO) – z. B. auf viva-deluxe-reinigung.de. Muss Zeiterfassung, Standort beim Stempeln (falls an), Kamera (QR, Fotos), Push-Nachrichten, Unterschriften erwähnen. Kann ich als Entwurf schreiben.
App-Zugriff„Alle oder einige Funktionen sind eingeschränkt“ → Test-Zugang für die Google-Prüfung angeben (eigener Benutzer, z. B. google.pruefung mit Passwort, Rolle ohne echte Personaldaten).
DatensicherheitErfasst: Name, E-Mail, Telefon, Arbeitszeiten, Fotos, ggf. ungefährer Standort; verschlüsselt übertragen (HTTPS); keine Weitergabe an Dritte; Löschung auf Anfrage.
Werbung / Zielgruppe / EinstufungKeine Werbung · Zielgruppe ab 18 · Fragebogen Inhaltseinstufung ausfüllen.

Danach Produktion → Neuen Release erstellen (dasselbe .aab) oder – empfohlen für eine reine Firmen-App – die App über einen geschlossenen Test bzw. „Private App“ (Managed Google Play) nur für die eigenen Leute verteilen.

Hinweis Konto: Google verlangt bei privaten Entwicklerkonten vor der Produktion einen geschlossenen Test mit mindestens 12 Testern über 14 Tage. Bei einem Organisationskonto (GmbH mit D-U-N-S 343512805) entfällt das.

Später: Updates

  • Neue Funktionen / Fehlerbehebungen kommen automatisch – die App lädt die Seiten vom Server. Kein Store-Update.
  • Nur wenn sich die Hülle ändert (Icon, Name, Berechtigungen, Plugins): in mobile-app\android\app\build.gradle versionCode um 1 erhöhen (2, 3 …), Schritt 4 + 5 wiederholen.
  • Push-Nachrichten in der installierten Store-App brauchen Firebase (Google) – im Browser/Home-Bildschirm-App funktionieren sie schon. Einrichtung folgt, wenn die App im Store ist.

iPhone

Für den App Store braucht es zusätzlich einen Mac mit Xcode und das Apple-Developer-Konto der GmbH (99 €/Jahr). Bis dahin: Safari → app.viva-deluxe-reinigung.de/app → Teilen → „Zum Home-Bildschirm“.
