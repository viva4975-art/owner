Zugangsdaten auf dem Server eintragen

Viva-Deluxe App · Server IONOS VPS 217.160.236.117 · Stand 08.10.2026

Worum geht es? Passwörter und Schlüssel (Mail-Zugang, später Qwist, Archiv-Speicher) gehören nicht in den Chat und nicht in den Programmcode, sondern nur in eine Datei auf dem Server: /opt/viva/deploy/.env.live. Nur der Server liest sie. Sie tragen dort einmal ein, starten die App neu – fertig. Dauer: ca. 10 Minuten.

Schritt 1 – Mit dem Server verbinden

Variante A (am einfachsten, im Browser):

  1. IONOS anmelden → Server & Cloud → den Server (217.160.236.117) anklicken.
  2. Oben rechts Aktionen → KVM-Konsole (auch „Remote-Konsole“) öffnen. Es öffnet sich ein schwarzes Fenster.
  3. Bei login: root eintippen, Enter, dann das root-Passwort (beim Tippen ist nichts zu sehen – normal), Enter.

Variante B (Windows/Mac): PowerShell (Windows) bzw. Terminal (Mac) öffnen und eingeben:

ssh root@217.160.236.117

Beim ersten Mal mit yes bestätigen, dann das root-Passwort eingeben.

Noch offen: Das root-Passwort stand im Chat – bitte direkt nach dem Anmelden ändern: passwd eingeben, neues Passwort zweimal eintippen. Neues Passwort nur im Passwort-Manager notieren, nicht weitergeben.

Schritt 2 – Datei öffnen

nano /opt/viva/deploy/.env.live

Es erscheint eine Liste mit Zeilen wie APP_ENV='test'. Mit den Pfeiltasten bewegen (die Maus geht hier nicht).

Schritt 3 – Werte eintragen

Ganz nach unten gehen (Pfeil ↓ bis zur letzten Zeile, dann Ende, Enter für eine neue Zeile). Je Wert eine Zeile: NAME='Wert' – Wert immer in einfachen Anführungszeichen, ohne Leerzeichen um das =. Gibt es den Namen schon (z. B. SMTP_HOST), die vorhandene Zeile ändern statt eine zweite anzulegen.

Mail-Versand (IONOS Exchange, buchhaltung@):

SMTP_HOST='smtp.exchange2019.ionos.de'
SMTP_PORT='587'
SMTP_USER='buchhaltung@viva-deluxe-reinigung.de'
SMTP_PASS='hier das Passwort des Postfachs'
MAIL_FROM='buchhaltung@viva-deluxe-reinigung.de'

Jede Zeile muss mit einem Hochkomma ' enden – fehlt es, startet die App nicht (Meldung „unterminated quoted value“). Absender bitte nur als Adresse ohne Namen und spitze Klammern eintragen.
Enthält das Passwort selbst ein Hochkomma ', bitte kurz melden – dann ändern wir es anders.

Später (erst wenn ich es Ihnen sage):

WofürZeilen
Bankabruf Qwist (neuen Schlüssel bei Qwist erzeugen, der alte stand im Chat) QWIST_CLIENT_ID='…'
QWIST_CLIENT_SECRET='…'
Revisionssicheres Archiv (S3 mit Object Lock) S3_ENDPOINT, S3_REGION, S3_BUCKET, S3_ACCESS_KEY, S3_SECRET_KEY
Nicht ändern: APP_ENV='test'. Solange dort test steht, gehen alle Mails nur an Ihre Testadresse (MAIL_TEST_RECIPIENT) – kein Kunde bekommt aus Versehen eine Rechnung. Umstellen auf live machen wir gemeinsam vor dem Echtbetrieb. Auch DATABASE_URL, DB_PASSWORD und SESSION_SECRET nicht anfassen.

Schritt 4 – Speichern und schließen

  1. Strg + O (Buchstabe O) → unten erscheint der Dateiname → Enter.
  2. Strg + X → zurück in der Konsole.

Schritt 5 – App neu starten

bash /opt/viva/deploy/update.sh

Dauert 1–3 Minuten. Danach https://app.viva-deluxe-reinigung.de neu laden.

Schritt 6 – Prüfen

  1. In der App eine Rechnung (Entwurf → Ausstellen) per E-Mail senden → die Mail muss an Ihre Testadresse kommen.
  2. Kommt nichts an, diese Meldungen anzeigen lassen und mir als Foto/Text schicken (ohne Passwörter): 
    cd /opt/viva/deploy && docker compose logs --tail 50 app
  3. Verbindung schließen: exit

Kurz zusammengefasst

ssh root@217.160.236.117          # bzw. KVM-Konsole im IONOS-Panel
nano /opt/viva/deploy/.env.live   # Zeilen NAME='Wert' eintragen
# Strg+O, Enter, Strg+X
bash /opt/viva/deploy/update.sh   # neu starten
