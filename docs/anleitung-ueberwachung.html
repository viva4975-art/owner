Ausfallmeldung einrichten

Viva-Deluxe Betriebs-App · https://app.viva-deluxe-reinigung.de · Stand 10.10.2026

Die App prüft sich selbst alle 5 Minuten: Datenbank, E-Rechnungs-Prüfung (KoSIT), Speicherplatz, tägliche Sicherung, Mailzugang und (sobald eingerichtet) die Archiv-Kopie. Bei einer Störung kommt eine E-Mail – höchstens einmal am Tag je Störung, bei Behebung eine Entwarnung. Stand: Einstellungen → Systemzustand & Ausfallmeldung.
Fällt der ganze Server aus (Stromausfall, IONOS-Störung, Server hängt), kann er sich nicht selbst melden. Dafür braucht es einen Wächter von außen – Schritt 2 und 3 (kostenlos, je 5 Minuten).

1Wer bekommt die Meldungen?

  1. Standard: die Empfänger unter Einstellungen → Erinnerungen per E-Mail (sonst die Firmen-E-Mail).
  2. Eigene Adresse nur für Störungen: auf dem Server in /opt/viva/deploy/.env.live eine Zeile ALERT_EMAIL='ahmed@viva-deluxe-reinigung.de' ergänzen, dann ./update.sh (siehe Server-Anleitung). Pflicht für die Meldung „Datenbank nicht erreichbar“.
  3. Voraussetzung: Mailzugang (SMTP) ist eingetragen – sonst kann die App keine Mail schicken.

2Externer Wächter für die App (UptimeRobot)

  1. uptimerobot.com → „Register for FREE“ (E-Mail bestätigen).
  2. „+ New monitor“ → Typ Keyword (geht auch: HTTP(s)).
  3. URL: https://app.viva-deluxe-reinigung.de/health/voll
  4. Keyword: ok · „Alert when keyword does not exist“ · Intervall 5 Minuten.
  5. Benachrichtigung: E-Mail; zusätzlich die UptimeRobot-App aufs Handy (Push) – empfohlen.
  6. Test: Monitor zeigt „Up“. Bei einer Störung antwortet die Adresse mit „STOERUNG: …“ (Name der Prüfung) oder gar nicht → Meldung.

Der Wächter prüft dabei auch das HTTPS-Zertifikat (Ablauf wird gemeldet). Die Adresse verrät nur die Namen gestörter Prüfungen, keine Daten.

3Externer Wächter für die nächtliche Sicherung (healthchecks.io)

  1. healthchecks.io → kostenloses Konto → „Add Check“: Name „Viva Sicherung“, Period 1 day, Grace 3 hours.
  2. Die angezeigte Ping-Adresse kopieren (https://hc-ping.com/…).
  3. Auf dem Server in .env.live eintragen: BACKUP_PING_URL='https://hc-ping.com/…' (kein Update nötig – das Sicherungsskript liest die Zeile jede Nacht).
  4. Bleibt der Ping nach 02:30 aus (Sicherung fehlgeschlagen oder Server aus), meldet healthchecks.io per E-Mail.

4Was tun bei einer Meldung?

  • Datenbank / ganze App aus: Server-Anleitung → „Notfall“ (Status, docker compose ps, Neustart).
  • KoSIT: Rechnungen lassen sich nicht ausstellen; meist hilft ./update.sh bzw. ein Neustart der App.
  • Speicherplatz: alte Dateien in /opt/viva-sicherung prüfen, ggf. IONOS-Speicher vergrößern.
  • Sicherung zu alt: /opt/viva/deploy/backup.sh von Hand starten und die Ausgabe ansehen.
