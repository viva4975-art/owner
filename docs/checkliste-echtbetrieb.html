Cloud Backup: 100 GB gebucht, 0 belegtAhmed
Das heißt: Es ist noch nichts eingerichtet – das Paket ist nur gebucht. So geht es:
1) IONOS-Kundenbereich → Server & Cloud → Backup → „Backup-Konsole öffnen“ (Acronis).
2) Dort „Gerät hinzufügen“ → Linux. Die Konsole zeigt einen Befehl (Download + Registrierung mit Token). Diesen Befehl auf dem Server als root ausführen (ssh root@217.160.236.117).
3) Nach 1–2 Minuten erscheint der Server als Gerät. Sicherungsplan anlegen: Dateien/Ordner /opt/viva-sicherung und /opt/viva (oder ganzer Server), täglich 03:30 (nach unserer Datenbank-Sicherung um 02:30), Aufbewahrung 30 Tage.
4) Ersten Lauf von Hand starten, danach eine Datei probeweise zurückholen.
Prüfen: systemctl list-units | grep -i acronis zeigt den laufenden Agenten.
Revisionssicheres Archiv (GoBD, 10 Jahre)AhmedClaude
1) IONOS-Kundenbereich → Object Storage (S3) → Bucket anlegen, Region Frankfurt (de), Name z. B. viva-archiv.
2) Beim Anlegen „Objektsperre / Object Lock“ einschalten – das geht nur beim Anlegen, nicht nachträglich. Standard: Compliance-Modus, 10 Jahre.
3) Zugangsschlüssel (Access Key + Secret) erzeugen und nur auf dem Server eintragen:
S3_ENDPOINT='<Endpunkt laut IONOS>'
S3_REGION='<Region laut IONOS>'
S3_BUCKET='viva-archiv'
S3_ACCESS_KEY='…'
S3_SECRET_KEY='…'
(Endpunkt und Region zeigt IONOS beim Bucket an – genau so übernehmen.) Ich baue die Anbindung: jede Rechnung, E-Rechnung, Beleg und jedes Protokoll wird zusätzlich dort gespeichert und kann 10 Jahre lang von niemandem gelöscht werden – auch nicht von uns. Kosten: wenige Euro im Monat.
Rechnungsnummern beim UmstiegAhmed
Ja, der Fortytools-Export (invoices.xml) kann beliebig oft erneut eingespielt werden – bereits übernommene Rechnungen werden nicht doppelt angelegt, neue kommen dazu, „bezahlt“ wird übernommen. Der Nummernkreis der App wird dabei automatisch über die höchste Fortytools-Nummer gehoben (nie gesenkt).
Wichtig: Solange in Fortytools noch Rechnungen geschrieben werden, in der App keine echten Rechnungen ausstellen – sonst bekommen zwei Rechnungen dieselbe Nummer (§ 14 Abs. 4 Nr. 4 UStG: Nummer einmalig). Am Umstiegstag: letzte Rechnung in Fortytools, Export einspielen, ab dann nur noch die App.
Rechnungen ohne E-Mail-AdresseAhmed
Neu: Wo keine Rechnungs-E-Mail hinterlegt ist, kann nicht gemailt werden. Entweder in der Rechnungsgruppe die E-Mail eintragen oder an der Rechnung „Als versendet markieren“ (Post, persönlich, Fax).

Apple Developer Program – Problem mit „ä“Ahmed
Apple prüft den Firmennamen gegen den Eintrag bei Dun & Bradstreet. So vorgehen:
1) Unter developer.apple.com/enroll/duns-lookup die D-U-N-S 343512805 nachschlagen – dort steht der Name genau so, wie Apple ihn erwartet (oft mit „ae“ statt „ä“, z. B. „Viva-Deluxe Gebaeudereinigung GmbH“, oder anders als gedacht, z. B. „… Gebäudeservice“).
2) Diesen Namen Zeichen für Zeichen so eintragen (ae statt ä, Bindestriche, Leerzeichen, „GmbH“).
3) Passt es trotzdem nicht: Apple Developer Support kontaktieren (developer.apple.com/contact → Membership and Account → Enrollment) und D-U-N-S + Handelsregisterauszug nennen – Apple gleicht dann von Hand ab. Alternativ den Eintrag bei D&B korrigieren lassen (dauert bis zu 14 Tage).
Kosten 99 €/Jahr. Danach mich als Entwickler einladen (App Store Connect → Benutzer).
